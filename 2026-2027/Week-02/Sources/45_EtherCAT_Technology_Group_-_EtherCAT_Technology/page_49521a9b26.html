EtherCAT SubDevice Implementation Guide

The ETG.2200 SubDevice Implementation Guide describes the first steps with EtherCAT when starting an EtherCAT SubDevice implementation and consists of four parts:

  • Section I deals with principal aspects of an EtherCAT SubDevice implementation. Chapter 1 provides a brief EtherCAT technology background focusing on the SubDevice. In chapter 2 the implementation steps for a SubDevice are described, containing SubDevice implementation criteria and a list of useful tools. Exemplary implementation notes are given here, too. Chapter 3 describes support which is provided by the EtherCAT Technology Group.
  • Section II contains device specific descriptions for further implementation aspects. An overview to available evaluation boards is given in chapter 1. Following is a list of available EtherCAT Communication Modules in chapter 2, and EtherCAT SubDevice Controller (ESC) in chapter 3.
  • Section III gives an overview of the EtherCAT enhancement “EtherCAT P”, including all related implementation topics.
  • Section VI describes from a very practical point of view which topics have to be kept in mind for a successful usage and/or implementation of the Safety over EtherCAT (FSoE) technology.

The EtherCAT SubDevice Controller (ESC) overview gives a brief technical comparison of the ESCs available from different vendors.

The EtherCAT Device Protocol Poster describes the main principles of EtherCAT, the frame structure and its processing in the EtherCAT SubDevice Controller (ESC). It provides details about used registers and objects, regarding the logical ESC units. It is aimed to support the developer during the development process and provide a convenient access to further information about the respective specification by giving a structured and practical overview.
